# Security

Не прикладывайте к Issues signing keys, signing.json, токены, cookies или данные аккаунта.

Уязвимости сообщайте через [Private reporting](https://github.com/pyanexya/ympatcher/security/advisories/new). Если форма недоступна, запросите её включение без публикации чувствительных подробностей.

Укажите канал и версию патчера, ОС, Java, версию исходного клиента и минимальные шаги воспроизведения. Исправления готовятся в dev и переносятся в stable.
