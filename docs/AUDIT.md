# Аудит — 5 сентября 2026

Проверен tracked snapshot проекта перед переносом в новый репозиторий. Старую Git-историю сохраняем локально; новая публикация содержит текущие исходники. Это технический аудит, а не заключение о причинах блокировки GitHub или юридическое разрешение на распространение чужого кода.

## Найдено и исправлено

- В сохранённом APKS v0.5.0 все 12 встроенных библиотек Presence имели ZIP Deflate; 12 исходных библиотек оставались в ABI splits. Добавлены Stored-упаковка всех .so/resources.arsc, выравнивание .so на 16384 байта и остальных несжатых файлов на 4 байта. Нормализация выполняется до подписи, layout проверяется после подписи.
- Раньше локальный APKS мог записываться с расширением .apk, оставаясь контейнером. Теперь .apk означает настоящее объединение manifest, resources.arsc и splits; .apks явно сохраняет split-формат.
- Добавлена команда convert для APKS/APKM и ремонта APK без повторного применения патчей. Перед merge проверяются сертификаты, package/versionCode и уникальность config splits; dynamic feature modules отклоняются.
- Добавлены ограничения размера/числа файлов, проверка путей Windows/Zip Slip, коллизий имён и API fileName. Вложенная папка splits поддерживается с безопасным переносом APK.
- Сбой сборки больше не удаляет предыдущий выходной файл; публикация результата выполняется через временный файл.
- Исправлен panic при обрезке длинного UTF-8 stderr.
- Сохранены начатые владельцем изменения opt-in Presence. Добавлена защита Java-вызовов native update и clear при завершении сессии; успешная компиляция не исключает ошибки или native crash внутри закрытого SDK.
- Удалены workflows автоматической публикации пропатченного клиента, отчётов и отправки в Discord. Выгрузки reports/android исключены из Git, локальные файлы сохранены. В CI публикуется только executable инструмента.
- Добавлены запрет бинарников/ключей и проверка известных шаблонов секретов. В 232 исторических Git blobs не найдено совпадений с проверенными шаблонами; исторических APK/APKS/APKM/AAR/JAR/SO/keystore paths не найдено. Это не доказательство отсутствия любых возможных секретов.
- Обновлены scraper/selectors с удалением неподдерживаемой fxhash, а также отозванная chacha20 0.10.1 → 0.10.2. Повторный cargo audit для Cargo.lock: без уязвимостей и предупреждений.
- Документация и ссылки приведены к pyanexya/ympatcher; релизный workflow работает от main и имеет write-доступ только в publish job.

## Оставшиеся ограничения

- Подключённого ADB-устройства нет. Установка, запуск, вход, воспроизведение, Discord RPC и обновление установленного клиента в этой проверке не тестировались.
- ZIP alignment не меняет ELF program headers. Совместимость самих сторонних библиотек с 16 КБ страницами требует отдельной проверки/пересборки.
- Поддерживается один base и config splits, а не произвольный bundletool archive со всеми device variants или dynamic features. Недостающие ABI/ресурсы не генерируются.
- Исторический installer/ — отдельный старый wrapper для APKS с ограниченным выбором density; для новой выдачи используется единый APK.
- Google Play/API discovery и юридическая допустимость изменения/использования клиента не подтверждаются unit-тестами. Закрытый Discord SDK не проходил аудит исходников.
- Причина прошлой блокировки неизвестна без уведомления GitHub. Удаление рискованных сценариев публикации не гарантирует отсутствие будущих ограничений.
